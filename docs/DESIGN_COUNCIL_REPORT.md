# مجلس الخبراء: تدقيق وإعادة هيكلة تصميم Klaro Core ERP

المرجع البصري: صورة "Cloud Dock" (سايدبار داكن بنفسجي، محتوى فاتح، بطاقات كبيرة الزوايا، بطاقة مميّزة داكنة، تبويبات حبّة، أفاتار متراكب، شريط تقدّم).
المهارات المستخدمة: enterprise + roku (من Awesome Design Skills) كأساس للتوكنز والمكوّنات، accessibility-review للإتاحة، web-artifacts-builder للمعاينة. ملاحظة: brand-guidelines هي هوية Anthropic (برتقالي/Poppins/Lora) وتتعارض لونيًا مع مرجع التصميم، فاستُخدمت منهجيتها فقط (توكنز دلالية + خطوط بديلة) لا ألوانها.

## الخبير 1 — UX وبنية المعلومات (نظام ERP / محاسبة / مبيعات)
| # | الفجوة (دليل من الكود) | التحسين |
|---|---|---|
| 1 | السايدبار فاتح وبنفس وزن المحتوى؛ التنقل لا يتميّز بصريًا، والعناصر الإدارية (Workflows/Audit/Config/IAM/Blueprint/Settings) مختلطة مع التشغيلية في قائمة واحدة مسطحة | سايدبار داكن بمجموعات: «التشغيل» و«الإدارة» مع عناوين أقسام |
| 2 | الشريط العلوي يحوي مسار تنقل ولغة فقط؛ لا بحث ولا إجراءات سريعة | بحث عام ⌘K، زر لغة، بطاقة المستخدم، وتبديل دور واضح |
| 3 | الداشبورد يعرض JSON Preview وقائمة إعداد للمنفّذ قبل أرقام المبيعات | ترتيب: KPIs ← بطاقة مميّزة ← نشاط/مستندات؛ الأدوات التقنية في الأسفل |
| 4 | لا ترويسة صفحة موحّدة (عنوان + وصف + أزرار) بين 11 شاشة | مكوّن PageHeader موحّد |
| 5 | لا حالات فارغة/تحميل موحّدة | بطاقات Empty/Skeleton بنفس الأسلوب |

## الخبير 3 — الإتاحة وRTL والأداء
| # | الفجوة | التحسين |
|---|---|---|
| 1 | نص بشفافية 40–65% (148 موضع) تباينه ≈ 2.9:1 (يفشل 1.4.3) | رمز muted ثابت بتباين ≥ 4.8:1 |
| 2 | focus-visible في 5 أماكن فقط مقابل 42 outline-none | حلقة تركيز عامة :focus-visible بنفسجية |
| 3 | نصوص 9–11px (10 مواضع) | حد أدنى 12px |
| 4 | role/aria محدود (4 و20) والجداول 12 بلا scope/caption | role للتبويبات، aria-current للتنقل، scope=col |
| 5 | RTL: الخصائص المنطقية مستخدمة أصلًا (نقطة قوة) لكن أيقونات الأسهم تُقلب يدويًا | الحفاظ عليها وتعميمها في المكوّنات الجديدة |
| 6 | حزمة JS واحدة 1.58MB؛ والبناء الأصلي كان ينكسر لغياب react-is | إصلاح react-is ثم تقسيم lazy للشاشات الثقيلة |
| 7 | prefers-reduced-motion مدعوم أصلًا | الإبقاء |

## الخطة
1. توكنز + خطوط + مكوّنات أساسية في index.css (بطاقة، زر، حبّة، تبويبات، جدول، شارة).
2. تحويل آلي للألوان الحرفية إلى توكنز، وإزالة scale، ورفع التباين.
3. إعادة بناء AppShell (رايل أيقونات + سايدبار داكن مجمّع + بحث + بطاقة ترقية/حالة) وLoginView وDashboardView.
4. تطبيق على بقية الشاشات والتحقق: tsc + build + لقطات شاشة عربي/إنجليزي.
5. (لاحقًا، بعد الانتهاء) مراجعة الكود الوظيفية للتطبيق كما طلبت.

## تنبيه
ملف handoff.md في مشروع klaro يصف تطبيق Klaro Desktop (Electron، retail/inventory، مجلد desktop/) وهو غير موجود في هذا الريبو؛ الريبو هنا هو Klaro Core ERP (Vite/React/Firebase). عاملتهما كمشروعين مختلفين.
